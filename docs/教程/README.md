# SO-ARM101 项目零基础教程

> 从「完全不懂」到「能面试讲、能跟着做、大脑里有概念」
> 配套项目：`F:\robot_arm_atlas` · 硬件：Atlas 200I DK A2 + SO-ARM101 双臂 + 双相机

---

## 这份教程是给谁看的

这个项目全部由 AI 代理（agent）完成。你在使用它，但不一定理解它。这份教程的目标：

1. **面试能讲**：面对「你项目里做了什么？技术难点是什么？」能条理清晰地讲出来
2. **大脑有概念**：理解每一步在做什么、为什么需要、和别的东西是什么关系
3. **有条件能实操**：板子和机械臂在手边，教程里的命令可以跟着敲

## 学习路线（推荐顺序）

```text
第 0 篇  项目全景地图 ── 先看懂整张图，再进细节
   │
   ├──> 模块 1：硬件篇    认识机械臂和开发板（动手第一步）
   ├──> 模块 2：数据篇    LeRobot：怎么教会机械臂动作（遥操作采集）
   ├──> 模块 3：模型篇    SmolVLA 是什么，怎么在 A100 上训练
   ├──> 模块 4：部署篇    把模型搬上昇腾 NPU（CANN/ATC/OM）
   ├──> 模块 5：孪生篇    ROS2 数字孪生：让电脑里出现一只一模一样的机械臂
   └──> 模块 6：抓取篇    相机标定 + 视觉定位 + 抓取闭环
   │
   ├──> 面试速查：把六篇浓缩成能背的讲解稿
   └──> 优化方向：项目的不足与下一步规划（面试高频追问）
```

## 每篇的固定结构

```
1. 本篇目标        学完能回答什么问题
2. 一句话版本      30 秒讲清本篇
3. 背景故事        为什么需要这个东西
4. 核心概念        大白话 + 比喻解释
5. 实际操作        命令/代码 + 预期结果（有真机可做）
6. 踩过的坑        本项目真实遇到的坑
7. 面试怎么讲      对着面试官说的话（可直接背）
8. 自查清单        能复述出来 = 学会了
```

## 建议用法

- **第一遍**：只读每篇的「1 一句话版本 + 2 背景故事 + 3 核心概念」，把六篇串成一条线
- **第二遍**：带着真机做「5 实际操作」，每做完一步回来看概念
- **面试前**：只背「7 面试怎么讲」、`07_面试讲解速查.md` 和 `08_优化方向与遗留问题.md`（被问「项目有什么不足」时的弹药库）
