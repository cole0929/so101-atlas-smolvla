# SO-ARM101 末端轨迹记录与统计（项目 2）

> 日期：2026-08-16
> 工作区：`F:\robot_arm_atlas`
> ROS 包：`F:\robot_arm_atlas\ros2_ws\src\so101_visualization`

## 1. 目标

在 RViz 中实时显示机械臂末端（`gripper_frame_link`）走过的轨迹，并统计：

- 轨迹长度（弧长积分）
- 速度 / 加速度（差分 + 滑动平均平滑）
- 平滑度（曲率 κ = |v×a| / |v|³，越小越平滑）
- 画圆场景：自动检测闭合圈，每圈半径、与第一圈的重复误差（RMS / max）

## 2. 架构与数据流

```text
板端 /joint_states ──Zenoh──> WSL
        │
        ▼
joint_state_retime.py ──/joint_states_local──> robot_state_publisher ──/tf──> RViz2
        │
        ▼
ee_trajectory_recorder.py（本项目核心）
   ├── TF 查询 gripper_frame_link 位姿（base_link 系）
   ├── 采样 → 轨迹缓冲
   ├── 圆检测：回到起点附近（<20mm）且弧长 >15cm → 闭合一圈
   ├── 统计：长度/速度/加速度/曲率/圈半径/圈间误差
   └── 发布：
       ├── /ee_path    (nav_msgs/Path)        完整轨迹线
       ├── /ee_trail   (MarkerArray)          彩色轨迹（每圈一色）+ 末端球 + 实时统计文字
       └── /ee_stats   (std_msgs/String)      JSON 统计
```

## 3. 使用方式

### 3.1 实机（开发板只读桥 + WSL）

```bash
# 板端：启动只读关节状态桥（提供 /joint_states）
systemctl start so101-rviz-bridge.service

# WSL：一键启动（retime + robot_state_publisher + recorder + RViz2）
source ~/ros2_humble_env.sh
ros2 launch so101_visualization trajectory_viz.launch.py
```

### 3.2 无硬件自检（mock 关节源，画 3 圈）

```bash

source ~/ros2_humble_env.sh
export ROS_DOMAIN_ID=66 ROS_LOCALHOST_ONLY=1
ros2 run so101_visualization mock_joint_source.py --rate 30 --circles 3 --period 4.0

# 终端 2（WSL）：
export ROS_DOMAIN_ID=66 ROS_LOCALHOST_ONLY=1
ros2 launch so101_visualization trajectory_viz.launch.py
```

### 3.4 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--topic` | `/joint_states_local` | 采样触发的关节状态话题 |
| `--frame-id` | `base_link` | 轨迹参考坐标系 |
| `--target-frame` | `gripper_frame_link` | 跟踪的末端坐标系 |
| `--publish-rate` | 10 Hz | 可视化发布频率 |
| `--min-sample-dt` | 0.02 s | 最小采样间隔（50 Hz 上限） |
| `--circle-close-tol` | 0.02 m | 回到起点多少米内判定圈闭合 |
| `--circle-min-arc` | 0.15 m | 圈闭合所需最小弧长 |
| `--align-samples` | 120 | 每圈等弧长重采样点数（误差对齐） |
| `--speed-window` | 5 | 速度滑动平均窗口 |
| `--out-file` | 无 | 可选 CSV 轨迹导出 |

### 3.5 清空轨迹

```bash
ros2 service call /ee_trail/reset std_srvs/srv/Empty
```

## 6. 已知限制与后续

1. **圆检测启发式**：以「回到起点附近 + 最小弧长」判定闭合。若画圆起点漂移较大（>tol），需调大 `--circle-close-tol` 或改进为平面投影角度累计法。
2. **曲率为 0**：mock 测试中速度/加速度太小导致曲率被阈值过滤。实机运动幅度下曲率更有意义。
3. **MoveIt 画圆**：当前 recorder 纯被动记录。MoveIt 自动画圆时同样订阅 `/joint_states` 即可记录，无需改动。
4. **统计文字 Marker**：RViz 中 `stats` namespace 实时显示长度/速度/圈数。
