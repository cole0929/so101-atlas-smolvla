## 3. 关键技术点与踩坑记录

### 3.1 前置相机标定（教训最多）

**结论**：固定俯视相机（eye-to-hand）**不要用 `cv2.calibrateHandEye`**（它只有 eye-in-hand 模式，输出 camera→gripper）。用**几何法**：

1. 棋盘格平放桌面已知位置（中心 (0.293, 0, 0.003)，长边朝 Y）；
2. `solvePnP` → 相机在棋盘系位姿；
3. **关键**：`T_cam2base = [R.T | -R.T·t]`（rvec 是相机在物体系，直接用 R.T 组合，**不要**再加 T_b2base 平移——那会引入错误偏移）；
4. 自检：棋盘格中心反投影回 (29.3, 0, 0.3)cm 应分毫不差。

**三个连环坑**：
- ❌ `calibrateHandEye` 用于 eye-to-hand → 结果不可靠；
- ❌ 组合外参时多加 `T_b2base` 平移 → 棋盘格反投影偏 16cm；
- ❌ Z 轴方向 → 俯视相机光轴必须朝下（Z 负），用 Ry(π) 翻转。

**最终校准**：用物块真值（实测 (23,13)cm）反推棋盘格真实中心 (23.5, 7.0)cm（之前量的 29.3cm 偏了），双点验证：

| 物块实际位置 | 定位结果 | 误差 |
|---|---|---|
| (23, 13) cm | (23.0, 12.9) cm | ~0 |
| (18, -13) cm | (17.5, -14.3) cm | ~1.3cm |

### 3.2 手眼相机标定

- eye-in-hand 用 `cv2.calibrateHandEye` **正确**（输出 camera→gripper）；
- 内参 0.46px（优秀），外参平移 (-3.5, 63.7, -91.1)mm；
- ⚠️ 实测相机在夹爪**左侧 5cm**，但外参 y=+63.7mm——方向可能标反，导致手眼精定位 y 偏右（用 `--handeye-offset-y +0.05` 补偿）。

### 3.3 IK（逆运动学）

- 手写数值 IK：阻尼最小二乘 + 关节限位 + 线搜索 + 从「自然前伸」初始姿态出发（关键！零位姿态会陷入局部最优）；
- 位置误差可达 0.0cm（好初始猜测时）；
- `add_downward_wrist`：扫描 wrist_flex 让夹爪朝下（[0,0,-1]）；
- ⚠️ 局限性：接近工作空间边缘（z 很低时）误差增大（2.5cm 抓取位误差 ~3cm）。

### 3.4 执行控制

- `robot.send_action(action_dict(...))` 有 `max_relative_target` 限幅（默认 10°/次）→ **必须插值多步执行**，否则机械臂一次动不到目标；
- 读实际位置用 `robot.get_observation()`（不是 read_observation）；
- 坐标系：`gripper_frame_link` 是标定参考点（在夹爪下方 ~9.8cm），IK 用它做目标，但**夹爪实际咬合点在它上方**——这是「下爪戳物块中心」的根源，需 jaw_clearance 补偿。

### 3.5 网络/环境坑（记录在案）

## 4. 抓取脚本使用方式

### 4.1 dry-run（只打印计划）

```bash
cd /root/lerobot_project
/opt/lerobot061/bin/python 20_grasp_block.py --dry-run
```

### 4.2 实机抓取

```bash
cd /root/lerobot_project
/opt/lerobot061/bin/python 20_grasp_block.py \
  --handeye-offset-y +0.05 \    # 手眼 y 补偿（往左）
  --jaw-clearance 0.04          # 下爪在物块下边缘外侧 4cm（往基座方向）
```

### 4.3 参数说明

| 参数 | 默认 | 说明 |
|---|---|---|
| `--grasp-height` | 0.025 | 抓取高度（m） |
| `--approach-height` | 0.20 | 接近高度 |
| `--offset-x/y/z` | 0 | 抓取目标三维偏移 |
| `--jaw-clearance` | 0.015 | 下爪在物块 x_min 外侧距离（往基座方向） |
| `--handeye-offset-y` | 0 | 手眼精定位 y 补偿 |
| `--max-relative-target` | 30 | 单步关节限幅（度），自动插值 |
| `--test-move` | - | 只执行第一步 approach |

### 4.4 待调参方向（下次继续）

1. **下爪 x**：`--jaw-clearance` 从 0.04 起逐步增大（下爪往基座偏），直到下爪在物块下边缘外侧；
2. **y 对准**：`--handeye-offset-y` 已找到方向（+0.05 往左对），精调 ±0.01；
3. **z 高度**：`--offset-z` 负值降爪，让夹爪包住物块中部（z≈1.5cm）；
4. **手眼外参 y 方向**：建议重标定手眼外参（当前 y=+6.4cm 与实测「左侧 5cm」矛盾），根治 y 偏差。
